# Catálogo Turístico de El Salvador (Laravel MVC + JSON)

Este proyecto es un catálogo web interactivo de destinos turísticos de El Salvador desarrollado con el framework Laravel. Utiliza archivos JSON como fuente de datos para demostrar y analizar el funcionamiento del patrón de arquitectura **MVC (Modelo-Vista-Controlador)**.
